## 本次发布检查

- 导出仅允许五份 JS、两份布局、两份颜色及项目文档/安装器。
- JS 通过 Node 语法检查；这不等于全部 foobar 宿主接口已运行。
- 两份颜色 FTH 检查区段数、长度和 MD5，确保只含颜色区段。
- XML 做解析和本地资源引用检查，不声称通过已知存在问题的 Layout.xsd 全量验证。
- 安装器做 PowerShell 解析检查，并在包含中文和空格的临时模拟配置目录运行只检查及实际复制流程，核对文件哈希。不会为测试改动用户正在使用的配置。
