# 验证记录

## 本机历史显示验收

用户曾确认私人配置的四页面导航、沉浸歌词、右侧封面、模糊背景和底部频谱正常。公开版去除了许可不明确的借用图片，并提供独立歌词布局与颜色定义，因此历史截图不能当作公开版完整验收。

## 本次发布检查

- 导出仅允许五份 JS、两份布局、两份颜色及项目文档/安装器。
- JS 通过 Node 语法检查；这不等于全部 foobar 宿主接口已运行。
- 两份颜色 FTH 检查区段数、长度和 MD5，确保只含颜色区段。
- XML 做解析和本地资源引用检查，不声称通过已知存在问题的 Layout.xsd 全量验证。
- 安装器做 PowerShell 解析检查，并在包含中文和空格的临时模拟配置目录运行只检查及实际复制流程，核对文件哈希。不会为测试改动用户正在使用的配置。
- 扫描公开目录中的禁止文件类型、个人路径和凭据模式。

## 尚未验证

- 在全新 foobar + 最新 foobox 上完整启动和所有宿主接口行为。
- 公开版不含借用图片的 XML 逐项视觉验收。
- 任意 foobox 版本、便携配置、x86 / x64 全组合。

发布状态以仓库实际创建/推送结果为准，不以本地 git commit 代替 GitHub 发布成功。

本次实测结果：5 份 JS 语法检查通过；安装器 PowerShell 解析通过；中文空格路径 dry-run 未写入、Apply 的 9 份文件哈希一致且无关文件保留；2 份 FTH 仅颜色区段与 MD5 通过；2 份 XML 可解析且没有外部素材引用；覆盖层个人路径/常见凭据模式扫描未命中。
